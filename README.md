# Skill Mind AI

Skill Mind AI is an AI-powered learning platform.

## Backend

This repository contains the FastAPI backend.

## Features

- API health check
- AI-powered chat
- Environment-based API key configuration
- Interactive API documentation

## API Endpoints

- `GET /` — Service status
- `GET /health` — Health check
- `POST /chat` — Send a message to the AI

## Security

Store API keys in environment variables. Never commit secrets to GitHub.
